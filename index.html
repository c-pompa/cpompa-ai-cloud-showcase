cpompa-ai-cloud — Multi-tenant AI agent hosting platform

A learning project: I built it to walk the whole path of a software business myself — the engineer who builds it, the CEO who prices and bills it, and the user who pays for it.

An OpenRouter-style control plane: users pick a plan, then call a fleet of models through an OpenAI-compatible endpoint metered in units, or deploy their own cloud Hermes agent with tools, logs, and streaming turns. Multi-tenant FastAPI + PostgreSQL/Redis on my own hardware, with Stripe (test-mode) subscription billing and API-key management.

Highlights:

  • plan entitlements that fail closed
  • hardened Docker runtime — non-root, no package manager at runtime, SHA-pinned deploys with rollback + smoke checks
  • alembic schema migrations
  • full CI security pipeline (below)

Hermes Agent — desktop plugin suite (6 plugins)

Six production plugins for the Hermes desktop app + backend, all thin-plugin/fat-core (stdlib-only cores, backend APIs mounted at /api/plugins/<id>/):

  • fork-upgrader — tracks upstream drift on a vendored fork and drives a gated prepare → test → publish → deploy upgrade pipeline from the desktop.
  • smart-router-studio — GPU-fleet model catalog with size/guardrail budgeting and SSH-probed multi-host downloads.
  • model-router — presence-aware role-alias router with registered read-only agent tools.
  • metrics-dashboard — live LLM request metrics, health findings, and usage map.
  • model-providers and hermes-achievements (a session-scanning achievement engine).
